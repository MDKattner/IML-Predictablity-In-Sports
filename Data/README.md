# Data files

## League structures (read this first)

The processed data reduces each league to **division-level tournaments**: within a division
each season, every pair of teams plays a fixed set of games, giving a small, self-contained
tournament to measure upsets in. All three leagues cover the same window, **1985–2024**, and
differ in ways that matter for the analysis:

| League | Structure | Games per intra-division pair | Tied series |
|---|---|---|---|
| MLB | 5 realignment eras; divisions of 4–7 teams (6 divisions of 5 since 2013) | 5–20 (13 only in 2023–24) | 154 (6% of series) |
| NBA | 9 eras; 4 divisions of 5–8 teams until 2003, 6 divisions of 5 since 2004 | 4–6, mostly 4 | 602 (22% of series) |
| NFL | 5 eras; 6 divisions of 4–6 teams until 2001, 8 divisions of 4 since 2002 | 2, always | 853 (41% of series) |

Season labels are **start-year** (e.g. NBA "2004" = the 2004-05 season).

Division membership is not in the game log, so it comes from documented league history; how far
each league's assignments could be checked against the schedule is described in `Notes.md`.
Tied series are normal in all three leagues (an even number of games per pair is common); the
upset definition counts a tied series as 1/2 an upset (see `Notes.md`).

**Open item (division naming):** MLB divisions are named `AL-East` / `NL-West`, NFL divisions
`AFC-East` / `NFC-Central`, and NBA divisions `Atlantic` / `Pacific` (no conference). This
inconsistency is unresolved and flagged for the group.

## Original Data

Game data collected in Fall 2026 IML project.

- **game_data_us_leagues.csv** (~181,000 rows): Game-by-game results for MLB, NBA, and NFL,
  dating back to 1980. Each row is a single game.
  Columns: `season, date, league, team1, team2, result, score1, score2`.
  `result`: 1 = team1 win, -1 = team2 win, 0 = tie/draw.

- **game_data_premier_league.csv**: Game-by-game results for the English Premier League.
  Same structure as above, with additional columns for home/away points (3 pts for win,
  0 for loss, 1 for draw).

- **mlb_teams.csv, nba_teams.csv, nfl_teams.csv, premier_league_teams.csv**: Auxiliary files
  listing team names and abbreviation codes for each league. Note: `mlb_teams.csv` uses `WAS`
  for the Washington Nationals (matching the Retrosheet-style codes used in the game data),
  not `WSH`.

## Processed Data

Every league has two processed files, generated by the scripts in `scripts/`:

- **`<league>_division_membership.csv`**: one row per season per division.
  Columns: `season, league, division, teams`. `teams` is a parenthesized, comma-separated tuple
  of team codes sorted alphabetically, e.g. `(BAL,BOS,NYA,TBA,TOR)`.
- **`<league>_division_series_results.csv`**: one row per pair of teams in the same division per
  season (team1 < team2 alphabetically).
  Columns: `season, league, division, team1, team2, result, wins1, wins2, ties, games_played`.
  `result` is the team code of the series winner, or `TIE` if wins1 == wins2 (`TIE` is not a team
  code in any league, so it is unambiguous). `ties` is the number of individual games in the
  series that ended tied, and `games_played` is the total games between the pair that season.

| League | Membership rows | Results rows | Notes |
|---|---|---|---|
| MLB | 222 | 2,503 | 5 eras (1985–92, 1993, 1994–97, 1998–2012, 2013–24); sizes 4–7; 3 franchise code changes |
| NBA | 202 | 2,778 | 9 eras; sizes 5–8; period-correct codes (NJN→BKN, SEA→OKC, NOH/NOK/NOP, VAN→MEM) |
| NFL | 286 | 2,059 | 5 eras; sizes 4–6; franchise codes already normalized to present-day in the log |

Generated by `build_<league>_division_membership.py` and
`build_<league>_division_series_results.py`.

## anomalies/

Evidence files for data irregularities (MLB) and for expected-but-recorded features (tied series
and schedule variation in all three leagues, tied games in MLB and NFL), including `mlb_ties.csv`
(every MLB game in 1985–2024 that ended tied). See `anomalies/README.md` for details.

## Analysis outputs

Scoring sequences and upset counts computed from the processed data above are written to the
top-level `Analysis/` folder, one pair of files per league:

- **`<league>_scoring_sequence.csv`**: one row per team per season, with the team's division
  score. Columns: `season, league, division, team, wins`. (MLB 1,158 rows, NBA 1,147, NFL 1,229.)
- **`<league>_upset_counts.csv`**: one row per division-season (one tournament).
  Columns: `season, league, division, upset`. (MLB 222 rows, NBA 202, NFL 286.)

They are produced by the notebooks in `scripts/`.
