This folder contains data files created inFall 2025 IML Project.

- *game_data_premier_league.csv, game_data_us_leagues.csv*:   Game results data for Premier League and US Leagues (MLB, NBA, NFL).  Results are encoded as 1 for win (for the home team), -1 for loss, 0 for draw/tie.  For Premier League games, home team and away team points are also included (3 pts for win, 0 for loss, and 1 for draw).
-  *mlb_teams.csv, etc*: Auxiliary files listing team abbreviations.
