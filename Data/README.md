# Data files

## League structures (read this first)

The processed data reduces each league to **division-level tournaments**: within a division
each season, every pair of teams plays a fixed set of games, giving a small, self-contained
tournament to measure upsets in. The leagues differ in ways that matter for the analysis:

| League | Scope built | Structure | Games per intra-division pair | Ties in a series |
|---|---|---|---|---|
| MLB | 1985–2024 | Varies by era (5 realignment eras); 6 divisions of 5 only since 2013 | Varies 5–20 by era; odd (13) only 2023–24 | Rare recently; 154 tied series historically |
| NBA | 2004–2024 | Fixed: 6 divisions of 5 (2 conferences × 3) | 4 (even) | Common (2–2), and expected |

Season labels are **start-year** (e.g. NBA "2004" = the 2004-05 season).

**Why these scope cutoffs:**
- **MLB (1985–2024):** the project's chosen span; covers all division realignments since 1985.
- **NBA (2004–2024):** 2004-05 is the first season of the current 6-division-of-5 alignment.
  Before that the NBA had **4 larger divisions** (different tournament sizes), and the pre-2004
  division assignments aren't recoverable from the game log alone — they need a citable source,
  so that range is **deliberately deferred**, not done. (NFL, same structure of problem, is the
  next league to add.)

The even games-per-pair in the NBA mean **tied series are normal, not anomalies** — the upset
definition handles them by counting a tied series as 1/2 an upset (see `Notes.md`).

**Open item (division naming):** MLB divisions are named `AL-East` / `NL-West` (league-prefixed)
and NBA divisions `Atlantic` / `Pacific` (bare, no conference). This inconsistency is unresolved
and flagged for the group.

## Original Data

Game data collected in Fall 2026 IML project.

- **game_data_us_leagues.csv** (~181,000 rows): Game-by-game results for MLB, NBA, and NFL,
  dating back to 1980. Each row is a single game.
  Columns: `season, date, league, team1, team2, result, score1, score2`.
  `result`: 1 = team1 win, -1 = team2 win, 0 = tie/draw.

- **game_data_premier_league.csv**: Game-by-game results for the English Premier League.
  Same structure as above, with additional columns for home/away points (3 pts for win,
  0 for loss, 1 for draw).

- **mlb_teams.csv, nba_teams.csv, nfl_teams.csv, premier_league_teams.csv**: Auxiliary files
  listing team names and abbreviation codes for each league. Note: `mlb_teams.csv` uses `WAS`
  for the Washington Nationals (matching the Retrosheet-style codes used in the game data),
  not `WSH`.

## Processed Data — MLB

All MLB processed files cover seasons 1985–2024 (40 seasons, including the strike-shortened 1994
and COVID-shortened 2020 seasons). Generated by scripts in `scripts/`.

- **mlb_division_membership.csv** (222 data rows): Maps each season and division to the teams
  in that division. One row per season per division. Covers all 5 MLB realignment eras
  (1985–92: 4 divisions of 6–7; 1993: expansion to 28 teams; 1994–97: 3-division
  realignment; 1998–2012: expansion to 30 teams; 2013–24: current alignment).
  Columns: `season, league, division, teams`.
  `teams` is a parenthesized, comma-separated tuple of team codes sorted alphabetically,
  e.g. `(BAL,BOS,NYA,TBA,TOR)`. Division sizes vary from 4 to 7 depending on era.
  Generated by `scripts/build_mlb_division_membership.py`.

- **mlb_division_series_results.csv** (2,503 data rows): Head-to-head records for every pair
  of teams in the same division, for every season 1985–2024. One row per ordered team pair
  per season (team1 < team2 alphabetically).
  Columns: `season, league, division, team1, team2, result, wins1, wins2, ties, games_played`.
  `result`: the team code of the division-series winner, or `TIE` if wins1 == wins2.
  `ties`: number of individual games in the series that ended in a tie (rare — see
  `mlb_ties_1985_2024.csv`). `games_played`: total games between the pair that season
  (historically varies from 5 to 20; exactly 13 only in 2023–2024).
  Generated by `scripts/build_mlb_division_series_results.py`.

- **mlb_ties_1985_2024.csv** (21 data rows): Every MLB game in 1985–2024 that ended in a
  tie (result = 0 in the game data). These are rain-shortened or otherwise suspended games
  that were never completed. 13 of the 21 were between division rivals.
  Columns: `season, date, league, team1, team2, result, score1, score2`.
  Generated by `scripts/find_ties.py`.

## Processed Data — NBA

NBA processed files cover seasons 2004–2024 (21 seasons), the modern 6-division-of-5 alignment.
Generated by scripts in `scripts/`.

- **nba_division_membership.csv** (126 data rows): Maps each season and division to the teams
  in that division. One row per season per division (6 divisions × 21 seasons). The alignment
  is constant across the window; three franchises appear under a changed code partway through
  (New Jersey → Brooklyn 2012, Seattle → Oklahoma City 2008, New Orleans NOH/NOK → NOP), which
  the script resolves per season.
  Columns: `season, league, division, teams` (same format as MLB).
  Generated by `scripts/build_nba_division_membership.py`.

- **nba_division_series_results.csv** (1,260 data rows): Head-to-head records for every pair of
  teams in the same division, every season 2004–2024 (6 divisions × 10 pairs × 21 seasons).
  Columns identical to the MLB results file. Because the NBA plays an even 4 games per
  intra-division pair, tied series (2–2) are common (310 across the window), not anomalies.
  Generated by `scripts/build_nba_division_series_results.py`.

## anomalies/
