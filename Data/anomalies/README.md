# Anomalies

Evidence files for data irregularities found while building the processed data. The **MLB** files
document genuine irregularities (suspended games, uneven schedules, tied series from even game
counts). The **NBA** files document features that are *expected* rather than erroneous (the NBA
plays an even number of games per pair, so tied series are normal) — they are recorded here
because the upset analysis has to account for them. All files are generated by the
`build_*_division_series_results.py` scripts.

---

## MLB (1985–2024)

### games_played_variation_1985_2024.csv
Per season, the distinct games-played-per-pair counts. Columns:
`season, distinct_games_played_counts` (`;`-separated). The count ranges **5–20** by era and is
often even; only 2023–2024 have the clean "exactly 13" property. Notable: 1994 (strike, as few as
5), 2020 (COVID, 10).

### tied_division_series_1985_2024.csv
Pairs whose head-to-head series ended with **equal wins** — **154** across 1985–2024. Columns:
`season, division, team1, team2, wins1, wins2, ties, games_played`. Common because so many
seasons had an even number of games per pair; each feeds the 1/2-upset rule.

### individual_tie_games_in_division_1985_2024.csv
Intra-division pairs whose series included at least one **tied individual game** — **13** across
1985–2024 (the in-division subset of the 21 total MLB tie games in `mlb_ties_1985_2024.csv`).
Columns: `season, division, team1, team2, ties, games_played`. For these, `wins1 + wins2 <
games_played`, which is why the results file carries a separate `ties` column.

## NBA (2004–2024)

### nba_games_played_variation_2004_2024.csv
Per season, the distinct games-played-per-pair counts. Normally **4**; blips reflect real
schedule disruptions — 2011 (lockout), 2019–2020 (COVID), 2023.

### nba_tied_division_series_2004_2024.csv
Pairs whose head-to-head series ended 2–2 — **310** across 2004–2024. These are **expected**, not
errors (even games per pair), and are recorded because each feeds the 1/2-upset rule. Columns:
`season, division, team1, team2, wins1, wins2, ties, games_played`.

(No individual-tie-games file for the NBA: modern NBA games always have a winner.)
