# Anomalies

Evidence files for data irregularities found while building the processed data, plus features
that are *expected* but must be accounted for in the upset analysis (tied series, schedule
variation). Nothing listed here is removed from the data; these files document it. All files are
written by the `build_<league>_division_series_results.py` scripts, except `mlb_ties.csv`
(written by `scripts/find_mlb_ties.py`).

Every league has a **games-played variation** file and a **tied series** file. MLB and NFL also
have a tied-games file, because their games can end tied; NBA games always have a winner.

---

## MLB

### mlb_games_played_variation.csv
Per season, the distinct games-played-per-pair counts. Columns:
`season, distinct_games_played_counts` (`;`-separated). The count ranges **5–20** by era and is
often even; only 2023–2024 have the clean "exactly 13" property. Notable: 1994 (strike, as few as
5), 1995 (strike carry-over), 2020 (COVID, 10).

### mlb_tied_division_series.csv
Pairs whose head-to-head series ended with **equal wins** — **154** across 1985–2024. Columns:
`season, division, team1, team2, wins1, wins2, ties, games_played`. Common because so many
seasons had an even number of games per pair; each feeds the 1/2-upset rule.

### mlb_ties.csv
Every MLB game in 1985–2024 that ended in a **tie** (`result == 0`) — **21** games, 13 between
division rivals and 8 across divisions. These are suspended or rain-shortened games that were
never completed. Columns: `season, date, league, team1, team2, result, score1, score2`.
Generated by `scripts/find_mlb_ties.py`.

### mlb_individual_tie_games_in_division.csv
Intra-division pairs whose series included at least one **tied individual game** — **13** across
1985–2024 (the in-division subset of `mlb_ties.csv`). Columns:
`season, division, team1, team2, ties, games_played`. For these, `wins1 + wins2 < games_played`,
which is why the results file carries a separate `ties` column.

## NBA

### nba_games_played_variation.csv
Per season, the distinct games-played-per-pair counts: 5–6 in 1985–88, 4–6 in 1989–94, 4–5 in
1995–2003 (one 5-game pair per season; 3–4 in the 1998 lockout season), and exactly 4 in
2004–2024 except the disrupted seasons (2011 lockout, 2018, 2019–20 COVID, 2023).

### nba_tied_division_series.csv
Pairs whose head-to-head series ended level (2–2, or 3–3 in 6-game series) — **602** across
1985–2024. **Expected**, not errors (an even number of games per pair), and recorded because each
feeds the 1/2-upset rule. Same columns as the MLB file.

---

## NFL

### nfl_games_played_variation.csv
Per season, the distinct games-played-per-pair counts: exactly **2** in every season except 1987
(the players' strike), where the log holds only 12 games per team and pairs played 1 or 2 games.

### nfl_tied_division_series.csv
Pairs whose two games were split 1–1 (or tied) — **853** across 1985–2024. **Expected** with only
two games per pair, and recorded because each feeds the 1/2-upset rule. Same columns as the MLB
file.

### nfl_individual_tie_games_in_division.csv
Intra-division pairs with a **tied individual game** (NFL games can end tied after overtime) —
**10** pairs across 1985–2024 (21 tied games in all, 11 between non-division teams). Columns:
`season, division, team1, team2, ties, games_played`.

## Irregular seasons

Seasons whose game counts differ from the standard schedule. All are **included** in the data.

| League | Season | What the log shows |
|---|---|---|
| NFL | 1987 | Strike: 12 games per team; many division pairs played once |
| NBA | 1998 | Lockout: 50 games per team |
| NBA | 2011 | Lockout: 66 games per team |
| NBA | 2019 | COVID suspension: 64–75 games per team, uneven |
| NBA | 2020 | 72 games per team |
| NBA | 2018 | 1,228 games instead of 1,230; BOS–PHI has 3 games (cause not established) |
| NBA | 2023 | Four division pairs have 5 games (BOS–NYK, IND–MIL, LAL–PHX, PHX–SAC); cause not established |
| NBA | 2012 | BOS and IND have 81 games; not division rivals, no effect |
| NFL | 2022 | BUF and CIN have 16 games (cancelled game); not division rivals, no effect |
| MLB | 1994, 1995, 2020 | Strike-shortened (1994–95) and COVID (2020) seasons |

See `Notes.md` for how these are handled.
